### Challenges ASP.NET Core

This repository contains a series of backend challenges designed to practice and master ASP.NET Core development. 

### 🚀 Challenge 1: Product CRUD API

Create a new ASP.NET Core Web API to manage a simple list of items. Each product must have an Id, Name, and Description. 

### 📋 Requirements

* **Controller:** Create a ProductsController.
* **Data Storage:** Do not use a database. Use an in-memory list (List<Product>).
* **Model:** Create a Product class.
* **Architecture:** Organize the project files cleanly and logically.

### 🛣️ Endpoints

* GET /products - Returns the complete list of products.
* GET /products/{id} - Returns a specific product by its ID (products/2).
